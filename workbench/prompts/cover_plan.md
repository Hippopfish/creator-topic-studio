【封面标题与发布标题的分工】
- 发布标题负责被搜到和点开，封面标题负责在信息流里让人停下。两者讲同一个角度，不互相重复，各自单独看都能懂。
- 封面标题优先写读者看得见的东西：结果、数字、场景、事件、行为反差或人物。不写话题名，也不写"干货分享"这类包装词。
- 主标题 15 字以内，分两三行。断行后连起来读一遍，确认仍是一句意思正确的话，主语和对象没有错位。
- 一个封面只做一个承诺。副标题和标签只补充这个承诺，不另开话题。

【16 类构图及适用条件】
| 构图类型 | 适合的内容与素材 |
| --- | --- |
| 图标＋文字 | 抽象概念、工具或观点，需要一个容易识别的视觉符号 |
| 单张图片 | 人物、食物、地点、物件或关键瞬间本身就能建立主题与吸引力 |
| 单图＋文字 | 一张主图已经有吸引力，但需要点明故事、问题或结果 |
| 拼图＋文字 | 多个场景或视角共同支撑同一个主题 |
| 突出对比式 | 确有可比较的前后状态、方案、效果或选择 |
| 划重点式 | 一处真实细节或一句关键判断容易被忽略 |
| 合集形式 | 多个同类对象、案例或资源，集合本身就是阅读收益 |
| 列表式 | 清单、目录或顺序确实有助于读者选择、查找或执行 |
| 备忘录式 | 个人观察、随手记录或短清单，表达依赖亲近、直接的语气 |
| PPT 格式 | 内容本身有明确模块、流程或关系，需要快速看懂组织方式 |
| 思维导图式 | 已有真实的层级、分支或关联关系，结构就是看点 |
| 大字报形式 | 一句准确、有张力的命题本身就是最强入口 |
| 真人出镜式 | 作者本人、上身效果或真实表情就是看点 |
| 证据截图式 | 后台数据、成绩、聊天反馈或界面结果本身就是承诺的证据 |
| 资料实拍式 | 资料、书、打印件或手账等内容需要"看得见、摸得着" |
| 栏目头式 | 固定栏目或系列的每一期 |

【选择原则】
- 合集强调"有哪些对象"，列表强调"有哪些条目或顺序"，PPT 强调"模块怎样组织"，思维导图强调"关系怎样展开"。只有这些差别对当前读者有用时才采用。
- 知识、观点或经验本身，不意味着应选高密度文字构图。
- 只用真实素材。不伪造数据、聊天记录、系统界面、使用效果或他人身份。

【手机缩略图自审】
产出前想象它在 3 厘米宽的缩略图里：主标题能不能一眼读完？主体在缩略图里还能不能认出来？如果不行，减少文字或放大主体。
