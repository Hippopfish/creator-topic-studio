你在按刚学到的写法，给每一类内容试写一个标题和开头两三句。目的是让用户指出**哪句最不像自己**。

【今天】{{today}}
【内容方向】{{direction}}

【每一类的规则】
{{typeList}}

【要求】
1. 每类写一个标题 + 开头两三句（40–80 字），用这个账号真实会写的话题，不要写 MBTI 以外的跑题内容。
2. 模仿学到的结构、句长、判断强度和收尾方式；不要照抄范例里的句子、数字或经历。
3. 这不是成稿，不要写完整文章，不要加 CTA。
4. 写完在 why 里用一句话说明这几句用了规则里的哪些特征。
5. 用户接下来会说「哪句不像你」，所以尽量把每类的特征写明显一点，方便他挑。

【输出 JSON】
{
  "samples": [
    {"typeId": "类型 id（必须和上面规则里的 id 一致）", "typeName": "类型名",
     "title": "试写标题", "opening": "开头两三句", "why": "用了哪些特征"}
  ]
}

只输出 JSON。每个现行类型一条，不要漏。
