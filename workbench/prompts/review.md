复盘一条已发布的内容。你要回答的是"这条表现怎么样、为什么、下一条改什么"，不是夸或安慰。

【这条内容】{{publishTitle}}
【发布时间】{{publishedAt}}

【数据】
{{metricsText}}

标注「创作者后台」的那行是从平台后台直接读到的真实数字，含曝光和观看；
标「D0/D1/D3/D7」的是手工录入的。两者可能同时存在，以后台那行为准。

【同账号基线】
{{baselineText}}

【评论区意图分布】
{{commentGroupsText}}

【第一步：一句话结论】
用倍数说，不用形容词。比如"D3 点赞是账号中位数 1.8 倍"，而不是"表现很好"。
判定口径：≥1.3 倍算超出预期，0.7–1.3 算正常，≤0.7 算低于预期。

【第二步：三层归因】
- 这一条：标题钩子、结构、发布时间、评论在追问或反驳什么。只讲这条本身能看出的东西。
- 模板层：如果这条用了某种固定形式（清单、对比、故事），这个形式本身是否有效。
- 账号层：定位、方向、风格、人设是否被印证。**没有证据就写"这条看不出"，不要硬编。**

【第三步：下一条可以做】
给 1–3 个具体建议。只建议，不要直接当成选题。

【第四步：建议存为长期经验，最多 3 条】
每条必须：一句话可执行 + 层面标签 + 依据哪个数据 + 标不标"待验证"。
层面只有四个：account（账号）/ template（模板）/ topic（选题）/ expression（表达）。
依据不充分的一律标"待验证"。

【禁止】
- 不许用"互动率高""数据不错"这种没有基准的话
- 不许把单条表现直接上升为规律（样本 1 条不能证明任何模板有效）
- 不许编造数据里没有的数字
- **不许由点赞推算曝光、播放、完播或涨粉。** 后台没给就是「暂无后台数据」，缺失写「—」，不写 0
- 数据只有一次观测、看不出增长时，就说"只有一次观测，看不出增长"，不要按天数估算

【输出格式：只输出 JSON】
{
  "conclusion": {
    "oneLine": "一句话结论，带倍数",
    "thisPost": "这条本身的问题或亮点",
    "template": "形式层面的判断，没有就用空字符串",
    "account": "账号层面的印证或未印证，看不出就写这句"
  },
  "suggestions": [
    {
      "text": "一句话可执行的建议",
      "layer": "account|template|topic|expression",
      "basis": "依据哪个数字或哪条评论",
      "pending": true
    }
  ]
}
